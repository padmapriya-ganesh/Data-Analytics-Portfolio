# 🏦 Project: Study Customer Churn Analytics For The Banking Industry

### 📋 Overview
* **Domain:** Business Analytics
* **Role:** Business Analyst
* **Partnership:** Mentor-led Internship (“Menternship”) • Jupiter × MentorMind

---

### 🚀 Key Contributions & Methodology

* **Exploratory Data Analysis (EDA):** Analyzed a 10,000-customer banking dataset using SQL (PostgreSQL), uncovering 7 churn indicators (4 strong, 3 moderate) through EDA, segmentation (filtering), and summary statistics (aggregate functions).
* **Risk Modeling:** Leveraged SQL window functions and risk-scoring models to flag the top 10 high-risk customers for retention, recommending personalized interest rate reductions for the top 5.
* **Data-Informed Retention:** Delivered a comprehensive analytics report with data visualizations, churn metrics, and segmentation insights to drive data-informed retention strategy.
* **Stakeholder Communication:** Created a leadership-focused presentation translating complex analytical findings into clear, non-technical insights with actionable customer retention strategies.
